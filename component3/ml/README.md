# Component 3 machine learning

- `training/cnn/` contains CNN training and inference entry points.
- `training/notebooks/` contains the CNN and recommendation experiment notebooks.
- `training/configs/` contains reproducible model configurations.
- `models/recommendation/phase8b/` contains the frozen recommendation artifacts
  consumed by the backend recommendation service.

Runtime navigation and recommendation services remain under `component3/backend/`;
this folder is reserved for model training resources and trained artifacts.
